# Production Lines

A **production line** is a set of machines and workstations that work together to make a product. Each line in the system has its own name, code, and status so you can track what is happening on every line at a glance.

## Adding a New Line

If your facility adds a new production line, an administrator can set it up in the system.

1. Go to **Production** in the sidebar.
2. Click the **Lines** tab.
3. Click **Add Line**.
4. Fill in the required fields:
   - **Name** — A descriptive name for the line (for example, "Assembly Line 3").
   - **Code** — A short code used to identify the line in reports (for example, "AL3").
   - **Type** — The kind of production the line handles (for example, UD, LM, CP, DBP, or Drawline).
   - **Location** — Where the line is located in your facility.
5. Click **Save**.

The new line will now appear on the Dashboard and in all drop-down menus throughout the system.

## Line Status

Every production line has a status that tells you what it is doing right now. There are four possible statuses:

- **Running** — The line is actively producing. Everything is normal.
- **Idle** — The line is not producing, but there is no problem. It may be waiting for materials or between jobs.
- **Maintenance** — The line is shut down for scheduled or unscheduled maintenance work.
- **Offline** — The line is completely shut down and not available for production.

## Viewing Line Status on the Dashboard

The **Dashboard** shows all of your production lines in one place.

1. Go to **Production** in the sidebar.
2. Click **Dashboard**.
3. Each line appears as a card showing its name, current status, and key numbers.

Lines that are **Running** are shown in green. Lines in **Maintenance** are shown in orange. **Idle** lines are shown in yellow, and **Offline** lines are shown in gray.

> Tip: If a line's status is wrong, contact your supervisor. Only users with the right permissions can change a line's status.
