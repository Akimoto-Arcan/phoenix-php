# Logging Production Runs

A **production run** is one batch of production on a specific line. Every time a line starts making a product, you create a run to track how much was made, how much was good, and how long it took.

## Creating a Run

1. Go to **Production** in the sidebar.
2. Click the **Runs** tab.
3. Click **New Run**.
4. Fill in the required fields:
   - **Line** — Select the production line from the drop-down menu.
   - **Product Name** — Enter or select the product being made.
   - **Target Quantity** — Enter the number of units you plan to produce in this run.
5. Click **Start Run**.

The run is now active. It will appear on the Dashboard under the selected line.

## Updating a Run

As production continues, you need to update the run with actual numbers.

1. Find your active run on the **Runs** tab or click on the line from the **Dashboard**.
2. Click **Update Run**.
3. Enter the quantities:
   - **Good Quantity** — The number of units that passed quality checks.
   - **Reject Quantity** — The number of units that failed quality checks and cannot be reworked.
   - **Scrap Quantity** — The number of units that are waste and must be discarded.
4. Click **Save**.

You can update a run as many times as needed throughout the shift.

## How Efficiency Is Calculated

The system calculates **efficiency** using this formula:

**Efficiency = (Good Quantity / Target Quantity) x 100**

For example, if your target was 500 units and you produced 450 good units, your efficiency is 90%. The system also factors in downtime — time the line was not producing reduces your available production time.

> Tip: Update your run numbers regularly throughout the shift, not just at the end. This gives supervisors a real-time view of how production is going.

## Completing a Run

When the batch is finished, you need to close out the run.

1. Open the active run.
2. Make sure all quantities are up to date.
3. Click **Complete Run**.
4. Confirm that you want to finish the run.

Once a run is completed, it cannot be edited. If you made a mistake, contact your supervisor to have it corrected.

> Warning: Always double-check your quantities before completing a run. Completed runs are locked and require a supervisor to make changes.
