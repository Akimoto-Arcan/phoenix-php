# Managing Users

User management is where you control who can log in to the system and what they can do. This guide covers viewing users, creating accounts, approving registrations, disabling accounts, and resetting passwords.

## Viewing the User List

1. Go to **Admin** in the sidebar.
2. Click **Users**.
3. The user list shows all accounts in the system, including their name, role, status, and last login date.

Use the **Search** box at the top to find a specific user by name or username.

## Creating a New User

1. Go to **Admin** and click **Users**.
2. Click **Add User**.
3. Fill in the required fields:
   - **Username** — The name the person will use to log in. This cannot be changed later.
   - **Full Name** — The person's first and last name.
   - **Email** — Their email address, used for notifications and password resets.
   - **Password** — A temporary password. The user should change it after their first login.
   - **Role** — The user's job role, which controls what they can see and do (see the Roles and Permissions guide for details).
   - **Groups** — One or more groups the user belongs to. Groups provide additional permissions beyond the basic role.
4. Click **Save**.

The new user can now log in with the username and password you provided.

## Approving New User Registrations

If self-registration is enabled, new users can create their own accounts. These accounts must be approved by an administrator before they can be used.

1. Go to **Admin** and click **Users**.
2. Look for accounts with a **Pending** status.
3. Review the account details to make sure the registration is legitimate.
4. Click **Approve** to activate the account, or **Reject** to deny it.

> Tip: Check for pending registrations regularly. New employees may be waiting for approval before they can start using the system.

## Disabling a User Account

When someone leaves the company or no longer needs access, you should **disable** their account rather than deleting it. Disabling keeps their history in the system for reporting purposes but prevents them from logging in.

1. Go to **Admin** and click **Users**.
2. Find the user and click on their name.
3. Click **Disable Account**.
4. Confirm the action.

The user will no longer be able to log in. Their name will still appear in historical reports and records.

> Warning: Deleting a user account permanently removes their data. Always disable accounts instead of deleting them unless you have a specific reason to remove the data.

## Resetting a User's Password

If a user forgets their password, an administrator can reset it for them.

1. Go to **Admin** and click **Users**.
2. Find the user and click on their name.
3. Click **Reset Password**.
4. Enter a new temporary password.
5. Click **Save**.

Let the user know their new password and remind them to change it after they log in.
