# Creating and Managing Work Orders

## What Is a Work Order?

A **work order** is a task assigned to the maintenance team. It describes a specific job that needs to be done on a piece of equipment — such as a repair, inspection, or replacement.

Each work order includes what the problem is, which equipment is affected, how urgent it is, and who is responsible for completing it.

## How to Create a New Work Order

1. Click **Maintenance** in the main menu.
2. Click **Work Orders**.
3. Click the **New Work Order** button.
4. Fill in the following fields:
   - **Title** — A short summary of the task (for example, "Replace drive belt on LM2").
   - **Description** — A detailed explanation of the problem or what needs to be done.
   - **Equipment** — Select the machine or asset this work order applies to.
   - **Priority** — How urgent the task is (see priority levels below).
   - **Assigned To** — The maintenance technician responsible for completing the work.
5. Click **Save** to create the work order.

## Priority Levels

Each work order has a priority that tells the team how quickly it needs attention:

- **Emergency** — The equipment is down or there is a safety hazard. Fix immediately.
- **High** — The equipment is impaired or will be soon. Fix today.
- **Medium** — The issue needs attention but is not critical. Fix this week.
- **Low** — A minor issue or improvement. Fix when available.

> Tip: Use Emergency only for true emergencies. If everything is marked Emergency, the team cannot tell what to work on first.

## Status Flow

Every work order moves through a series of statuses as work progresses:

1. **Open** — The work order has been created but no one has started working on it yet.
2. **Assigned** — A technician has been assigned to the task.
3. **In Progress** — The technician is actively working on it.
4. **Completed** — The work is finished.
5. **Cancelled** — The work order was cancelled and will not be completed.

## How to Update a Work Order Status

1. Click **Maintenance**, then click **Work Orders**.
2. Find the work order and click on it to open the detail view.
3. Click the **Status** dropdown and select the new status.
4. Click **Save**.

## Adding Comments to a Work Order

Comments let you record notes, updates, or questions on a work order. This keeps all communication about a task in one place.

1. Open the work order detail view.
2. Scroll down to the **Comments** section.
3. Type your comment in the text box.
4. Click **Add Comment**.

All comments are saved with your name and a timestamp so everyone can see who said what and when.

## Viewing Work Order History

To see all past work orders for a piece of equipment:

1. Go to **Equipment** and click on the machine in question.
2. Scroll down to the **Work Order History** section.

This shows every work order ever created for that equipment, including completed and cancelled orders. It is useful for spotting recurring problems.

> Tip: If the same equipment keeps breaking down, review the work order history for patterns. Repeated issues may mean a bigger underlying problem needs attention.
